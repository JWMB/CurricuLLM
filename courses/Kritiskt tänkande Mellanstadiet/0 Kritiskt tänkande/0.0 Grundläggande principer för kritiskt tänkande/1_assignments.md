**Hint** Tänk på om uttalandet kan bevisas med kontrollbara uppgifter.

**InputType** text
**Hint** Det innebär att förvränga någons åsikt för att lättare kunna kritisera den.
**Hint** Exempel: A säger X, B säger något enklare att angripa, och kritiserar det i stället.
**Answer** Att förvränga någons argument till en enklare version och sedan kritisera den. Exempel: "Du vill ha mindre läxor" → "Du vill göra så att barn aldrig lär sig".
**MaxPoints** 3
**AnalyzeSubmission** Kontrollera att svaret beskriver att någon medvetet eller omedvetet förenklar eller förvränger en annan parts argument för att lättare angripa det, och att ett kort exempel ges. Ge full poäng för korrekt definition och exempel.
