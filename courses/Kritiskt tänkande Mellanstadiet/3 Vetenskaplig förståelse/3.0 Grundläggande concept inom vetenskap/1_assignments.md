## Svårighetsgrad 2

**Question** Vad innebär ordet "bias" i vetenskaplig forskning?
**Hint** Tänk på att det handlar om skevheter eller fördomar som kan påverka resultatet.
**Hint** Kan leda till selektivt urval av data eller vinklad tolkning.
**Answer** Bias innebär fördomar eller skevheter som kan påverka tolkningen eller insamlingen av data i forskning.
**MaxPoints** 3
**AnalyzeSubmission** Om användarens svar innehåller "fördomar", "skevheter", "påverka resultatet", svara "korrekt". Annars "inkorrekt".
**WrongAnswer** Bias är ett fel i utrustningen **Why** Bias är en mänsklig faktor som påverkar bedömning, inte en teknisk detalj.

**Question** Varför är det viktigt att identifiera felkällor i vetenskapliga undersökningar?
**Hint** Felkällor kan förvränga resultaten och göra dem mindre tillförlitliga.
**Hint** Tänk på hur det kan påverka slutsatser och framtida forskning.
**Answer** Felkällor kan leda till felaktiga resultat och slutsatser, vilket kan påverka trovärdigheten och generaliserbarheten hos forskningen.
**MaxPoints** 3
**AnalyzeSubmission** Om användarens svar innehåller "förvränga", "tillförlitliga", "påverka slutsatser", svara "korrekt". Annars "inkorrekt".
**WrongAnswer** För att spara tid **Why** Identifiering av felkällor är för att öka noggrannheten, inte för att göra forskning snabbare.

**Question** Hur kan forskare minska bias i en studie?
**Hint** Använd kontrollgrupper och dubbelblindtester.
**Hint** Se till att studien är så objektiv som möjligt genom att standardisera procedurer.
**Answer** Forskare kan använda kontrollgrupper eller dubbelblindtester och standardisera procedurer för att minimera bias.
**MaxPoints** 3
**AnalyzeSubmission** Om användarens svar nämner "kontrollgrupper", "dubbelblindtester", "standardisera", svara "korrekt". Annars "inkorrekt".
**WrongAnswer** Genom att fråga fler människor **Why** Att fråga fler människor kan öka datamängden men inte nödvändigtvis minska bias.

## Svårighetsgrad 3

**Question** Hur kan en felaktigt formulerad hypotes påverka resultatet av en studie?
**Hint** Om hypotesen inte är testbar, kan det leda till felaktiga slutsatser.
**Hint** Tänk på inverkan på trovärdighet och validitet.
**Answer** En felaktigt formulerad hypotes kan leda till undersökningar som är irrelevanta eller som inte kan testas, vilket påverkar trovärdigheten och validiteten av resultaten.
**MaxPoints** 5
**AnalyzeSubmission** Om användarens svar nämner "ej testbar", "felaktiga slutsatser", "trovärdighet", "validitet", svara "korrekt". Annars "inkorrekt".
**WrongAnswer** Det leder till fler experiment **Why** Problem är inte mängden experiment utan huruvida de ger tillförlitliga resultat.

**Question** Beskriv hur forskningsprojekt kan påverkas av kognitiv bias och hur detta kan undvikas.
**Hint** Kognitiv bias kan leda till att forskare tolkar data selektivt baserat på förväntningar.
**Hint** Försök tänka på metoder för att öka objektiviteten, som att använda flera bedömare.
**Answer** Kognitiv bias kan förvanska tolkningen av data. Det kan undvikas genom att använda flera bedömare, slumpmässigt urval, och blindtester.
**MaxPoints** 5
**AnalyzeSubmission** Om användarens svar nämner "tolka selektivt", "förväntningar", "objektivitet", "flera bedömare", "slumpmässigt urval", svara "korrekt". Annars "inkorrekt".
**WrongAnswer** Forskningsprojekt kan inte påverkas av kognitiv bias **Why** Påverkas eftersom mänskliga bedömningar är centrala för forskning vilket kan vara subjektivt.

**Question** På vilket sätt kan forskningsbias ofrivilligt introduceras i en studie och ge exempel på en åtgärd.
**Hint** Bias kan introduceras genom selektiv urval av data.
**Hint** Observera påverkansfaktorer från forskare och studiedeltagare.
**Answer** Forskningsbias kan introduceras genom att forskare omedvetet väljer data som stödjer deras förväntningar. Åtgärder kan vara att använda dubbelblindstudier för att minska sådan påverkan.
**MaxPoints** 5
**AnalyzeSubmission** Om användarens svar nämner "selektiv urval", "förväntningar", "dubbelblindstudier", svara "korrekt". Annars "inkorrekt".
**WrongAnswer** Bias är alltid avsiktligt **Why** Bias kan ofta vara omedvetet och bero på förväntningar och vanor.
