## Svårighetsgrad 1

**Question** Vad innebär ett ad hominem argument?  
**Hint** Tänk på kritik mot en person istället för argumentet de framför  
**Answer** Ett ad hominem argument angriper personen snarare än att bemöta deras argument.  
**MaxPoints** 1  
**AnalyzeSubmission** Om svaret liknar "angriper personen istället för argumentet", svara "korrekt", annars "inkorrekt".  
**WrongAnswer** Det är ett argument som bygger på fakta. **Why** Det handlar om personangrepp, inte objektiva fakta.

**Question** Ge ett exempel på ett ad hominem argument.  
**Hint** Fundera på hur man skulle kritisera någon baserat på deras personliga egenskaper  
**Answer** "Du kan inte lita på hans åsikt om miljön för han var inte bra på biologi i skolan."  
**MaxPoints** 2  
**AnalyzeSubmission** Leta efter exempel där kritiken är kopplad till personliga egenskaper istället för sakfrågor.  
**WrongAnswer** "Han har förstört miljön med sina beslut." **Why** Det är en kritik av handling, inte hans person.

**Question** Varför är ad hominem argument dåliga i kritiskt tänkande?  
**Hint** De berör inte sakfrågan eller beviset  
**Answer** De undviker att diskutera sakfrågan och fokuserar istället på irrelevanta personliga egenskaper.  
**MaxPoints** 2  
**AnalyzeSubmission** Om svaret nämner att ad hominem inte hanterar sakfrågor eller är irrelevant, svara "korrekt", annars "inkorrekt".  
**WrongAnswer** För att de ibland kan vara rätt. **Why** Även om det skulle vara sant angriper de fortfarande personen och inte argumentet.

## Svårighetsgrad 2

**Question** Hur kan man undvika att använda ett ad hominem argument i en debatt?  
**Hint** Fokusera på själva sakfrågan eller bevisen i stället för personen.  
**Answer** Genom att fokusera på argumentets styrka och den information som presenteras, inte debattörens personliga egenskaper.  
**MaxPoints** 3  
**AnalyzeSubmission** Leta efter om svaret nämner specifikt fokus på sakfrågor eller bevis istället för personen.  
**WrongAnswer** Genom att undvika att lyssna på personen. **Why** Det innebär att ignorera personen helt, snarare än att beakta deras argument korrekt.

**Question** Beskriv skillnaden mellan ett ad hominem argument och ett sakligt motargument.  
**Hint** Tänk på hur sakliga motargument ifrågasätter logik eller bevisning istället för personliga egenskaper.  
**Answer** Ett sakligt motargument kritiserar argumentets logik eller bevis, medan ett ad hominem argument kritiserar personen som framför argumentet.  
**MaxPoints** 4  
**AnalyzeSubmission** Kolla om svaret korrekt identifierar skillnaden mellan att diskutera sakfrågor och personangrepp.  
**WrongAnswer** De är samma sak. **Why** De adresserar olika aspekter; ett fokuserar på logik och det andra på person.

**Question** Användning av ad hominem argument kan ha vilken effekt på en debatt?  
**Hint** Tänk på hur debattens fokus kan förskjutas eller implodera.  
**Answer** Det kan distrahera från den ursprungliga sakfrågan och förminska kvaliteten på debatten.  
**MaxPoints** 3  
**AnalyzeSubmission** Leta efter om svaret nämner att fokus förskjuts eller debatten förlorar kvalitet.  
**WrongAnswer** Det gör debatten starkare. **Why** Fokus på personliga attacker kan försvaga debatten istället.

**Hint** Överväg hur publiken kan påverkas känslomässigt snarare än intellektuellt.  
**Answer** Ett ad hominem argument kan göra debatten mer polariserad genom att appella till känslor och skapa sympatier eller antipati utan att hantera sakfrågor.  
**MaxPoints** 5  
**AnalyzeSubmission** Leta efter om svaret beskriver effekt på publik, känslor och brist på sakfrågediskussion.  
**WrongAnswer** Det har ingen effekt. **Why** Debatten kan bli mer polariserad och minska sakligheten.

**Hint** Betänk vikten av rationell och logisk diskussion för vetenskapens trovärdighet.  
**Answer** Att använda ad hominem i vetenskapliga diskussioner kan underminera forskningens trovärdighet och avleder från faktuell evidensbaserad argumentation som är nödvändig för vetenskaplig integritet.  
**MaxPoints** 6  
**AnalyzeSubmission** Leta efter beskrivning av vetenskapliga diskussioners behov av integritet och rationell logik.  
**WrongAnswer** Det är alltid acceptabelt om det ger rätt resultat. **Why** Vetenskap kräver objektivitet och fakta, inte personangrepp.

**Question** Diskutera potentiella långsiktiga konsekvenser för samhällsdebatten om ad hominem argument blir allt vanligare.  
**Hint** Föreställ dig hur samhällsdialogen och problem lösning kan påverkas negativt.  
**Answer** Ad hominem kan minska möjligheten till konstruktiv dialog och skapa hinder för att lösa komplexa problem vilket kan leda till ett mindre informerat och mer polariserat samhälle.  
**MaxPoints** 7  
**AnalyzeSubmission** Leta efter om svaret nämner hinder för dialog och samhällseffekter av polarisation.  
**WrongAnswer** Det har ingen långsiktig effekt. **Why** Ökningen av ad hominem argumentering kan försvåra konstruktiv dialog och problem lösning.
