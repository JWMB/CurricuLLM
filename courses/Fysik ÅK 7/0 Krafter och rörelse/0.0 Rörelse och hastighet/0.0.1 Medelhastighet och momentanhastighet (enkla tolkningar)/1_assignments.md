**Answer** Medelhastighet är total sträcka / total tid; om tiderna vid varje hastighet skiljer sig måste man väga med tiden. Exempel: 60 km i 1 h + 60 km i 2 h → 120 km / 3 h = 40 km/h.

Om båda delar finns — "korrekt", om endast principen finns utan exempel — "delvis korrekt", annars — "inkorrekt".
**WrongAnswer** "Man tar bara medelhastigheten genom att lägga ihop och dela med två" **Why** Visar missförstånd om att inte väga hastigheterna efter tid eller sträcka.
